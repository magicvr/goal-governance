# 审计 · GOAL-005

## 说明

尚未到达阶段复盘节点。立项与决策已落盘后，建议在：

- 阶段 A（原则定稿）结束时做一次中期检查；
- 阶段 B/C 提示词与安装可用后做一次阶段审计；
- 成功标准全部满足后做关门审计（`close-out`）。

实践本目标能力时，审计条目应尽量使用将定义的意见结构（source / verdict / findings 等）。
