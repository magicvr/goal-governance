# R-017-A · 试点范围与证据模板（阶段 A）

> 本文件为 GOAL-017 **阶段 A 退出产物**。阶段 B 会话执行必须按本范围与模板记事实。  
> 冲突时以 **D-002 + 本文** 为准。会话填表用：[pilot-session-template.md](pilot-session-template.md)。

## 1. 范围与非目标

| 在范围内（有界试点） | 不在范围内 |
|---------------------|------------|
| 单用户、本机或可控 loopback 部署 | 多用户、公开互联网试点、账号体系 |
| ≥ **2** 个独立会话（可跨日；会话 = 浏览器/进程可区分的一段使用） | 把单次连点当「多会话」而不标注间隔 |
| 产品路径：N1 焦点 → 目标详情 → **只读审查** 和/或 **受控追加** | 新功能开发冲刺 |
| **建议**：至少 1 条会话触及 **AI 候选**（可关 AI）**或** **资料上传/引用** | 强制两条都含；AI 真联调全矩阵（R-014-E2E residual） |
| 故障、摩擦、改进点如实记录 | 编造成功、隐瞒失败 |
| 反馈列表作为 residual/backlog **输入** | 自动关 R-014/015/016-E2E 或 I-007/I-012 全文 |
| | 阶段 6 终态、Root done、关 R-009-X、X-DEPLOY |

## 2. 环境前置（会话前检查）

| 检查 | 要求 |
|------|------|
| `GOAL_GOVERNANCE_DATA_ROOT` | 指向**产品**数据根（非 monorepo dogfood 默认可写） |
| 工作区焦点 | N1 `/workspaces` 已选焦点，或多区未选时不假装有默认 |
| 受控写（若测写入） | 双门闩：`PRODUCT_GATES_OPEN` 默认关 + `ALLOW_CONTROLLED_WRITE=true`；单进程 residual 自觉 |
| AI（若测） | `AI_ENABLED` 与提供方配置显式；失败须记 fail closed 行为 |
| 资料（若测） | 同一 DATA_ROOT 下 materials；引用绑焦点工作区 |

## 3. 最小路径清单（会话脚本骨架）

每条会话至少覆盖 **P1～P3**；**P4 / P5 建议合计至少出现 1 次**（跨两条会话亦可）。

| 步骤 | 动作 | 可观察结果 |
|------|------|------------|
| **P1** | 打开 Web · 进入工作区列表 · 选择/确认焦点 | 焦点 id 可见；多区未选不进假详情 |
| **P2** | 进入某目标详情 · 阅读 canonical 与诊断 | 目标树/正文加载；无他区泄漏 |
| **P3a** 或 **P3b** | **a** 只读审查决策/执行/审计节 · **b** 受控追加一条 user-provided 执行事实（有门闩） | a：可读；b：committed 或明确拒绝码 |
| **P4**（建议） | AI：触发候选 → 确认/拒绝边界（未确认不写） | 候选展示；拒绝/确认路径可描述 |
| **P5**（建议） | 资料：上传 → 附加到焦点工作区引用 | 列表可见；refs 仅本焦点 |

## 4. 会话数与独立性

| 规则 | 说明 |
|------|------|
| 下限 | **2** 条完整会话记录（填模板） |
| 独立 | 不同时刻和/或不同浏览器配置和/或进程重启；须在记录中写明「间隔/区分方式」 |
| 失败会话 | **算数**；须记故障；不得删除以凑成功 |

## 5. 证据规则（硬）

1. 每条会话一份 `attachments/pilot-session-NNN.md`（从模板复制，NNN=001 起）。  
2. 只写**已发生**事实；计划标「计划」；不确定标「待确认」。  
3. 故障须含：复现步骤、期望、实际、环境摘要（无密钥）。  
4. 截图可选；若有放 `attachments/` 并在会话文件中链接。  
5. **禁止**把未跑路径勾成已完成。

## 6. 有界对照 I-007 / I-012（阶段 C 用 · A 先冻结表头）

| 信息项 | 试点可收集（有界） | 本目标**不**宣称 |
|--------|-------------------|-------------------|
| **I-007** | 实际用到的模型/提供方（若启用）、主观延迟/成本感、可见失败 | 完整成本矩阵、SLA |
