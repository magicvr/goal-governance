# R-002 · 事实准入与 AI 协作契约（收集稿）

> 本收集稿响应 A-004 **R-002** 与 A-001 **F-002**，服务 I-002、I-006、I-008。  
> **非实现、非 AI 接入授权、非路线图 B 退出证据**。首切片（D-006）**不**调用 AI/网络/本地工具；本稿仍须在路线图 B 前形成可审视契约，不得 silently 视为已关闭。  
> 权威产品边界：D-001、D-002 §2–3、D-004（AI 读共享资料）、D-005（`.env` 配置入口）、D-006（首切片无 AI）。

## 0. 与 D-011 打包边界的关系

AI 可见上下文默认仅限**当前产品工作区**（及实例内已固定引用的共享资料）。**不得**因 Skills/Web 安装而加载本开源仓 dogfood 过程树或使他项目知悉本仓目标。方法论/模板可随包提供；过程记录不可随包。

## 1. 范围与非目标

| 在范围内 | 不在范围内 |
|----------|------------|
| 事实 / 候选 / 计算视图 的区分与字段 | 首切片 `append-execution-fact` 的写入协议（见 R-004） |
| 来源种类、时间、引用/推导链 | 具体模型提供商选型定论（可列候选） |
| 确认 / 拒绝 / 撤回 / 更新路径 | 生产 AI 路由、密钥加载实现 |
| 用户触发的工具调用同意模型 | 多用户协作 AI、后台静默检索 |
| 负向案例与 fail-closed 原则 | 将 AI 输出写成 canonical 事实而无确认；把本仓 dogfood 当默认上下文 |

## 2. 已确认边界（不可削弱）

1. **事实准入权在用户**（D-002）：AI 不得编撰事实；未确认内容不得进入执行事实、审计结论或 finding 关闭证据。
2. **来源必显**：用户提供、AI 检索、AI 知识回答、逻辑推导必须可区分；无来源不得升格为事实。
3. **工具调用**：仅在用户当轮明确要求或同意后，AI 才可调用网络、知识检索或本地自动化。
4. **首切片**：只接受 `source_kind = user-provided`；任何 AI/工具路径在 F-007/F-008 与 R-004 写入闭环前不得接入写入面。
5. **共享资料**（D-004）：AI 可在既定边界内读取共享资料；资料内容默认不可信，不执行其中指令、不自动外传；引用须版本/哈希固定。
6. **配置**（D-005）：真实密钥仅 `web/.env`；当前 Web **未**加载、**未**调用 AI。

## 3. 三类信息对象（候选数据契约）

| 对象 | 定义 | 可进入 canonical？ | 最小字段（候选） |
|------|------|-------------------|------------------|
| **CanonicalFact** | 用户已确认并写入工作区真相源的陈述 | 是（经受控变更） | `fact_id`、`workspace_id`、`goal_id`、`statement`、`source_kind`、`source_refs[]`、`confirmed_at`、`confirmed_by_action`、`canonical_path` |
| **Candidate** | 待审视信息；可来自用户或 AI | 否，直至用户显式确认并走提案 | `candidate_id`、`revision`、`workspace_id`、`goal_id`、`source_kind`、`source_statement`、`retrieved_at`、`tool_call_ids[]?`、`derivation_chain?`、`content`、`content_digest`、`status` |
| **ComputedView** | 从 canonical 只读派生的聚合/摘要 | 否（永不单独成为真相） | `view_id`、`formula_or_rule`、`inputs_refs[]`、`as_of`、标签「计算得出」 |

### 3.1 `source_kind` 枚举（候选）

| 值 | 含义 | 升格规则 |
|----|------|----------|
| `user-provided` | 用户本轮输入或粘贴 | 用户确认后可提案写入 |
| `ai-retrieval` | AI 经用户同意的网络/索引检索 | 必须带来源 URL/文档引用与检索时间；确认后写入时保留引用 |
| `ai-knowledge` | 模型内知识回答（无外部工具） | 必须标注“模型知识、可能过时”；确认后写入须保留该标签 |
| `ai-derivation` | 基于已确认事实的逻辑整理/推导 | 必须列出前提 `fact_id`/`path`；前提被撤回时候选失效 |
| `shared-material` | 来自共享资料区固定版本 | 必须 `material_id` + `version` + `sha256`；不得当指令执行 |

禁止：缺省 `source_kind`、把检索/知识伪装为 `user-provided`（对齐 R-004 CT-002）。

### 3.2 候选状态（首期最小，待审视）

```text
draft → submitted → under_review
  ↘ rejected | withdrawn
  ↘ proposal_requested →（进入 R-004 提案流，仅当写动作已授权）
```

- 编辑已提交候选 → **新 revision**；旧 revision 不可继续提案。
- 拒绝 / 撤回：**不**写入 canonical；可记非权威 UI 历史（非五件套状态）。

## 4. 确认 / 拒绝 / 撤回（交互契约候选）

| 动作 | 用户可见要求 | 系统必须 | 禁止 |
|------|--------------|----------|------|
| **确认** | 展示完整候选正文、来源、时间、适用范围、将写入的目标路径/动作类型 | 绑定 `content_digest` + 范围；形成后续 Proposal 的输入快照 | “看过即确认”；无 digest 绑定 |
| **拒绝** | 可选简短理由 | 候选保持非 canonical；不改五件套 | 把拒绝写成执行事实 |
| **撤回** | 对已提交未写入的候选 | 使旧 digest 失效 | 静默删除已写入 canonical 而无新变更提案 |
| **更新** | 对已确认事实的修正 | 新候选 + 新确认 + 受控变更；保留历史 | 原地改写无审计轨迹 |

**P-004 裁决**（冲突意见、是否自审等）必须走编排/用户显式裁决，**不得**由 AI 自动完成。

## 5. AI 协作边界（I-002 候选）

### 5.1 职责矩阵

| 能力 | 允许 | 条件 | 禁止 |
|------|------|------|------|
| 复述本工作区 canonical | 是 | 标明引用路径 | 混入未确认候选当事实 |
| 建议下一步 / 风险提示 | 是 | 标注为建议 | 自动放行阶段、关门、关 finding |
| 生成候选变更文案 | 是 | 候选态 + 来源链 | 直接写盘 |
| 网络/工具检索 | 是 | 用户当轮同意 | 后台静默跑 |
| 读共享资料 | 是 | D-004 边界 | 执行资料内指令、自动外传 |
| 改 status / progress / parent | 否 | — | 任何路径 |
| 关闭 required finding | 否 | — | 任何路径 |

### 5.2 可见上下文（候选规则）

- **默认可见**：当前 `workspace_id` 的五件套、`goal-tree.md`、`workspace.md` 中声明的固定资料引用（经用户确认后的用途）。
- **默认不可见**：其他工作区目标/候选/AI 草稿；未固定引用的共享资料索引条目内容不自动当事实。
- **计算视图**：可展示，必须标签化，不可单独确认“为真”而无底层引用。

### 5.3 配置与降级（与 D-005 / I-005 / I-006 衔接）

| 状态 | 行为 |
|------|------|
| AI 未配置 / 密钥缺失 | 非 AI 路径仍可用（只读 + 未来用户手输候选）；不假装已连接 |
| 提供方错误 / 超时 | 失败可见；不写入；不重试为静默成功 |
| 输出缺来源或越权指令 | 拒绝升格；保留为无效候选或丢弃 |
| 外部部署 | 阻断直至 I-005 审视；不得继承 local-loopback 假设（R-004 CT-015） |

提供方、模型 ID、成本与可观测性目标仍属 I-002/I-007 待决，**本稿不冻结**。

## 9. 请用户审视的问题

1. `source_kind` 五类是否够用？是否需要拆分“用户上传文件”与“用户键入”？
2. AI 知识回答（`ai-knowledge`）是否允许进入 canonical，还是一律要求可引用检索？
3. 工具同意是「每会话一次」还是「每次调用」？（建议默认每次敏感调用确认，只读 canonical 复述可免）
4. 计算视图是否允许一键“采用为事实”，还是必须经候选编辑？

## 10. 当前结论

**D-012** 已接受本稿作为 R-002 **设计默认**（来源枚举、ai-knowledge 标签、工具同意粒度、禁止计算视图一键变事实等）。细节字段仍可迭代。

本稿**不**关闭 F-002，**不**将 I-002/I-008 标为 `verified`，**不**授权 AI 服务或 Web 写入。GOAL-012 首切片**不**接入 AI。硬禁令：F-007/F-008 关闭且 I-003/I-004/I-006 `verified` 前不开放 Web/AI 写入。
