# GOAL-013 · 独立审计命令派发与用户答复阻塞门禁

## 概述

承接用户 2026-10-16 提交的两项治理反馈，保护独立审计员自主发现问题的视角，并确保需要用户信息时真正等待答复。本目标位于本区 Root 的 R3「持续闭环与长期演进」，经父目标服务 VP-002。原始需求与本轮边界见 [D-001](01-decision/D-001-scope-and-roadmap.md)。

1. 编排器自动调用独立审计供应商时，向审计员提供的输入只允许为 `/audit <工作区编号> <目标编号>` 或 `/vision-audit <vp编号>`。禁止编排器自行编写、附加或包装审计提示词，以关注点、文件清单、阶段、结论预期等方式限制独立审计范围。目标解析与审计范围的独立判断由正式审计入口负责。
2. 需要向用户询问信息时，如宿主支持，使用能够阻塞当前任务的询问卡片，等待真实用户答复才能继续。卡片未收到答复（含空返回）时立即暂停任务；存在当前目标时将其置为 `blocked` 并同步目标树，保留待答问题与阻塞原因。禁止在缺失答复时自行推进、推定默认选择或以任何形式虚构用户答复。卡片不可用时采用文本提问并同样停止等待；收到真实答复且解除相应门禁后才能恢复。

S1～S4 已完成，按用户 2026-10-17 指令关门：当前 **done / 100%（4/4）**。代码检查点 e37cad3 与 S4 检查点 f86b406 之后完成 A-001 self、A-002 Grok independent、A-004 全部意见 fixed 响应及 A-005 关门审视；开放 required/recommended 0，无待答。关门决定见 [D-005](01-decision/D-005-close-out.md)，收尾事实见 [E-013](02-execution/E-013-close-out.md)，S4 事实见 [E-012](02-execution/E-012-s4-review-complete.md)。保证仍为 D-003 路径 A 及覆盖表的已列 profile，不新增系统硬拦截或未实测 GUI 主张；正式发布 v0.13.6 不在本目标内。

## 成功标准

- [x] 核心规范、治理编排入口、独立审计入口和相关安装适配面一致表达自动派发的命令白名单；调用侧不能以自编提示词收窄审计视角。
- [x] 两类命令的编号解析与入口路由明确；歧义或无法解析时停止并询问，不退回自由提示词，不错误选择工作区或台账。
- [x] 用户询问形成可核对的等待与恢复规则：有卡片用阻塞卡片；无答复/空返回暂停；有当前目标则 blocked、同步 goal-tree；无目标仍暂停任务；真实答复前无推进和伪造答复。
- [x] 正反例覆盖两类合法命令、追加提示/限制范围、无卡片、空答复、未提交预选项、真实答复与恢复；静态检查与真实宿主证据分别说明保证范围。
- [x] cross 审计的 self 与用户指定 provider 的 independent 意见正式落盘，相关 required finding 与到期 required 信息项合法闭合后完成关门审视。

前三项为 S2 规范与入口交付，不表示自动命令已有系统级代码拦截或实际宿主问答通过；后两项继续约束运行时验收与关门。
